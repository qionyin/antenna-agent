# Hybrid Retrieval 修改前后与 BM25Okapi 对比

测试集固定为同一批 1000 条：L2 500 条、L3 500 条；固定种子 `20260721`。

## 核心对比

| 模式 | Precision@K | 平均耗时 ms | P95 ms | 索引构建 ms |
|---|---:|---:|---:|---:|
| 修改前 Redis Hybrid | 35.19% | 22.141 | 31.862 | 0 |
| 修改后 Redis Hybrid | 35.92% | 28.971 | 43.461 | 0 |
| BM25Okapi | 35.93% | 0.159 | 0.281 | 0.380 |

## 修改效果

- Hybrid Precision@K 提升 `0.73` 个百分点。
- 成功召回率从 `86.88%` 提升到 `89.00%`。
- Top1 命中率从 `74.25%` 提升到 `77.88%`。
- `inactive` 目标已不再从 Hybrid 结果泄漏。
- 本轮观测平均耗时增加 `6.83 ms`；不同轮次受机器负载影响，需多轮基准确认。

## BM25Okapi 结论

- Precision@K 为 `35.93%`，与修改后 Hybrid 基本相同。
- 平均查询耗时 `0.159 ms`，明显低于 Hybrid。
- 成功召回率为 `73.00%`，低于 Hybrid 的 `89.00%`。
- 中文同义和长噪声输入仍是 BM25 的明显短板。

## 范围

本次只修改：失效记忆过滤、confidence 与相关性分离、相关分归一化。
未增加最低阈值，未改自适应 TopK，未替换本地 64 维哈希向量。
